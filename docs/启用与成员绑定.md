# 启用与成员绑定

## 启用智能体团队（`set-team`）与成员绑定（`bindMembers`）

「角色」页签最上面那个复选框是「**启用智能体团队**」。它问的是一个**部署层面**的问题：
dsh 的团队运行时（dsh 自带的组合包 `@deepseek-ai/dsh-experimental-agent-team-profile`）开没开。

- **团队运行时不是一个插件，是一个组合包（bundle）**：它把协作服务、团队工具、Web UI 三件一起挂上。
  dsh 安装目录里本来就有它，只是 profile 没选它 —— 用户自己那份 `<DSH_HOME>/profiles/web/package.json`
  的 `dsh.profile.bundles` 里就没有这一项，所以现在团队是**关**的。
- **怎么开**：点这个复选框。插件自己**不写** profile 文件，而是请 deployment 自己的核心服务
  `pluginManager` 去改选择（GUI 的插件页与 `dsh plugin` 走的也是它），同时把角色文件里的
  `bindMembers` 一起打开 ——「角色」只有在团队运行时里才有人可以绑。关掉时两个一起关。
- **结果如实显示**：`ChangeResult.application` 是 `applied` 就写「已生效」，是 `restart-required`
  就写「已保存，重启 dsh 后生效」。插件不替 dsh 下结论。
- 部署里没有 `pluginManager`（或安装里没有这个组合包）时，开关是**灰的**并写出原因，
  而不是显示成「关」骗人点一下。

### 成员绑定（`bindMembers`）—— 团队开着之后才有的第二步

默认**关闭**（跟随 `set-team`）。打开后，插件会在成员被创建的那个瞬间把它绑到同名角色上。
也可以把**插件配置**里的 `bindMembers` 设成 `true` 来**强制**打开（部署级决定，改完要重启；
界面上的按钮这时会置灰并说明是配置强制打开的）。插件配置写在哪由部署决定 —— 本仓把它写在
`cordis.patch.yml` 的 `config:` 段里，所以线上那条提示会点名这个文件；但提示本身说的是
「配置」这个**来源**，不代表那个文件里一定写了 `bindMembers` 键（不写就是默认关闭）。

> ⚠️ **怎么判断宿主半是不是新的**：看 `GET /state` 里有没有 `team` 段。没有 = 跑着的 dsh 还是旧宿主半，
> 那个复选框是灰的，界面会诚实提示「宿主半还没重启，重启 dsh 后这个开关才可用」。
> 重启之前，团队与成员绑定**怎么改都还没生效**。
> （等价的第二条判据：拿 `dsh web` 进程的 `StartTime` 与 `lib/index.js`（以及 `lib/host/` 下任意模块）的 mtime 比 ——
> mtime 更晚就说明这次运行装的是旧代码。看 `/state` 更省事。）

- **为什么需要**：子代理**默认继承父的 preset**（`dsh-subagent` 的 `applyChildComposition`：join its parent's preset），
  所以不干预的话，team 里每个成员拿到的都是 **Lead 的角色**。
- **怎么做**：监听 `agent/created`——这是「创建还没解析、会话还是空白」的唯一窗口，也正好是
  `agentPresets.select()` 接受改绑的时刻（一旦开过轮就抛 `agent-preset/locked`）。
  在这个窗口里读子会话自己的 `subagent/descriptor` 事件拿到 `label`，再按 `label` 匹配角色。
- **匹配规则**：`label` 先与 `role.name` 全等比较，再与「去掉 `prefix` 的 `role.id`」比较。
- **覆盖面**：**任何**带 `label` 的委派子代理都会参与匹配（不只是 team 成员）——
  `subagent({ description: 'reviewer', … })` 也会认领名为 `reviewer` 的角色。没有匹配就什么都不做。
- **失败不影响创建**：改绑失败只写一条 `warn` 日志，不会打断 `agent/created`。

```yaml
# cordis.patch.yml
config:
  dir: null          # 默认 ~/.dsh/agent-team-roles
  prefix: team-      # 角色 id 前缀
  bindMembers: true  # 打开成员绑定（默认 false）
```

⚠️ 这一项在**宿主半**（`lib/host/bind.js`），改动**要重启 dsh 才生效**——热加载只覆盖客户端半。
