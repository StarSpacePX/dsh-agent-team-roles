## 目标

`Project\dsh-agent-team-roles` 现在的群聊是「折 Lead 会话事件」的老方案（`lib/team-log.js`），
要换成 `plugins\dsh-agent-team-roles`（提交 `96fac69`）那套「插件自己消费两边事件、按团队落 jsonl 账本」。
手工改代码，不复制文件。

## 不动的范围

Project 独有的角色模型那套（`lib/host/member-model.js`、`src/client/panels/model.js`、provider / selection / llm 注入）、
`lib/notes.js`、`lib/host/state.js` 的非群聊部分、仲裁/派发链路，全部保留。

## 七、风险

1. 颜色与 `foldPairs` 两边**完全一致**（`useRoleColors`、`colorOfRow`、`chipStyle`、`foldPairs` 在 Project 与 plugins 同名同位），不属于分叉，不要动。
   `view.js` 只需要替换取数段（本文件第 16–49 行的 `pageIds`/`partners`/`page` 逻辑），并删掉 `p` 对象里的 `folded`、`onLoadOlder`、`busy` 三个老字段。
2. `view.js` 的渲染四段（`stats-row` / `graph-view` / `message-list`）接口靠 `p` 对象传递，改 `p` 的字段时要同步检查这三处。
3. 账本目录在老版本可能不存在，`readRows` 必须容忍缺文件（插件版已 try/catch 返回 `[]`）。
