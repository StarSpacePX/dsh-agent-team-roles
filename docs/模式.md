# 模式

每个角色要复制哪一套能力行，由角色自己的 `mode` 决定。

模式清单**不是写死的**：下拉框的选项来自这个部署**当前**的预设名册。
你在预设编辑器里新建或删掉一个预设，这里跟着变。

## 四个自带模式

| `mode` | 界面上叫 | 特点 |
| --- | --- | --- |
| `standard` | 标准模式 | 默认 |
| `ptc` | PTC | 多一行 `tool-presentation` |
| `minimal` | 极简 | 只有 `persona` + `persistent-shell`，**不读 AGENTS.md** |
| `cordis` | 创造 | 多一行 `tool-cordis` |

## 行为

- 详情最上面是一个下拉框，一个角色只有一个模式。
- **换模式 = 换整套能力行**：按新模式的组合重算，角色自己改过的行仍然优先。
  不动 `description`，也不动 `AGENTS.md`。
- 组不出来的模式在下拉框里禁用，标「（不可用）」，下面一行说明这一套行从哪来。
- 角色存着的模式若已不在名册里（预设被删了），补一条占位项——**角色仍然可读**，
  打开面板不会把它悄悄切走。
- `mode` 只允许 `[A-Za-z0-9._-]`；空值或非法字符回落 `standard`。
- 平台相关的行（`tool-bash` / `tool-pwsh`）按当前平台只挂一个。

宿主侧改动，**重启 dsh 才生效**。
