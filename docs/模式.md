# 模式

## 模式（从部署现有的预设里选一个）

每个角色要**复制哪一套能力行**，由角色自己的 `mode` 决定。**模式清单不是写死的**（§5.40，用户
m09580「从现有的模式中加载…不要写死」）：面板上那个下拉框的选项来自这个部署**当前**的预设名册
（`agentPresets.list()`），你在预设编辑器里删掉一个、新建一个，这里就跟着变。

组合（也就是「这一套能力行」）只有一个来源（§5.62，用户 m13273「1.只引用，不独立」）：

| 来源 | 什么时候用 | 从哪读 |
| --- | --- | --- |
| **实时声明** | 全部模式，包括 dsh 自带的四个 | `ctx.loader.entries()` 里那条 `@deepseek-ai/dsh-agent-preset` 声明，即 dsh 已解析好的 `{ id, plugins }`（`lib/live-template.js`） |

**插件不再自带任何模式快照**：以前那份抄本要跟着 dsh 升级重抽，还会和部署各说各话；现在角色组出来的
行永远等于**这个部署当前**的那套预设。四个自带模式：

| `mode` | 界面上叫 | 实际来源 | 顶层行 / 嵌套行 | 独有的一行 |
| --- | --- | --- | --- | --- |
| `standard` | 标准模式 | `@deepseek-ai/dsh-web-app/presets/standard.patch.yml` | 19 / 13 | —— |
| `ptc` | PTC | `…/presets/ptc.patch.yml` | 20 / 13 | `tool-presentation` |
| `minimal` | 极简 | `…/presets/minimal.patch.yml` | 2 / 5 | （只有 `persona` + `persistent-shell`） |
| `cordis` | 创造 | `…/presets/cordis.patch.yml` | 20 / 13 | `tool-cordis` |

- **默认 `standard`**。角色详情最上面是一个**下拉框**（`<select>`），选了就发 `set-mode`。
  一个角色只有一个模式，所以这里不是一排复选框——真画成复选会让 UI 说出数据表达不了的话。
- **换模式 = 换整套能力行**：以该模式的组合为准重新算一遍，角色自己改过的 overrides 仍然优先
  （同 id 的行用你改过的配置）。**不会**动 `description`，也不动 `AGENTS.md`。
- 选项自带 `source`：`live`（直接读部署当前的预设声明，`file` 是 `null`）/ `missing`（组不出来）。
  不可用的选项在下拉框里是禁用的，并标「（不可用）」；选中项下面一行说明它这一套行是从哪来的。
  角色存着的模式若已不在名册里（预设被删了），下拉框补一条占位选项——**角色仍然可读，打开面板不会
  把它偷偷切走**。
- 测试里那四份 `tests/fixtures/presets/<mode>.plugins.json` 是**夹具**（测试假装自己是部署用的输入），
  不是插件的运行时数据；想跟着新 dsh 刷新就手动 `node tools/sync-presets.mjs`，它**没有**接进 `npm test`
  ——dsh 升级不该让测试变红。
- `mode` 只允许 `[A-Za-z0-9._-]`；不合法或空值才回落 `standard`——**不认识的 id 不再被静默改成
  `standard` 了**，因为「部署里有这个预设、插件没见过」现在是正常情况。
- `minimal` 里**没有** `agent-instructions` 行，所以极简模式的角色不吃 `AGENTS.md`——
  `/state` 里那个角色的 `agentsMd.hasRow` 就是 `false`，界面据此提示你。
- ⚠️ 这一项在**宿主侧**（`lib/live-template.js` + `lib/host/modes.js`），改动**要重启 dsh 才生效**。


## 平台上不同的行怎么办

shipped 的 `standard` 用 `!!js process.platform === 'win32'` 这种表达式给 `tool-bash` / `tool-pwsh`
做平台门控。JSON 存不下表达式，快照里它们被写成 `{ "__js__": "process.platform === 'win32'" }`，
注册前由 `resolveGate()` 解析成具体布尔值。

只认 `===` / `!==` 两种形式；**看不懂的表达式一律当成「没有门控」**，而不是去猜——宁可多一行可用，
也不要有行被静默吃掉。
