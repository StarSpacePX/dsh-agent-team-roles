# 配置项

插件配置写在 `cordis.patch.yml` 的 `config:` 段。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `dir` | 空 | 角色数据目录；留空用 `<dsh home>/agent-team-roles` |
| `prefix` | `"team-"` | 自动生成的角色 preset id 前缀 |
| `bindMembers` | `false` | 强制打开成员绑定，改后重启 dsh 生效 |
| `home` | 空 | 数据根目录；留空走 `DSH_HOME` 或 `~/.dsh` |

没有 `template` 键：角色的模板就是它 `mode` 指定的那份预设，运行时现场读取。

## 成员绑定

两个来源，取或：

1. **插件配置** `bindMembers: true`：部署级，改后重启 dsh；
   面板会显示「已被插件配置强制打开」，开关置灰。
2. **界面开关**：随着角色数据走，随开随关，不用重启。

`GET /state` 回报最终是否生效，以及来源（配置 / 界面 / 关）。
