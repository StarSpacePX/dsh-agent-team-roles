# 身份与规则

每个角色有**自己的一份** `AGENTS.md`：新建角色时从 `$DSH_HOME/AGENTS.md`
（Windows 下 `%USERPROFILE%\.dsh\AGENTS.md`）复制一份，放在角色目录里。
角色目录同时就是角色的工作目录，所以 dsh 一定能读到它。

面板第一行显示这份文件的完整路径，以及它是从哪一份复制来的。

项目里的 `AGENTS.md` **不复制**：成员进入某个项目时，dsh 会按自己的发现链自动读到那个项目的规则。

## 三个发现键

| 字段 | 含义 | 默认 |
| --- | --- | --- |
| 指令文件名 | 从工作目录向上找哪些文件名 | `AGENTS.md, CLAUDE.md` |
| 本地指令文件名 | 本地覆盖文件 | `AGENTS.local.md, CLAUDE.local.md` |
| 项目根标记 | 找到哪一层为止 | `.git` |

留空 = 继承模板。默认值只作为提示文本显示，不会被自动写进角色数据。

## 两件事分开管

- 这个面板管**去哪几个文件名里找**。
- 要不要加载 AGENTS.md，由能力行表里 `agent-instructions` 那一行的开关决定
  （关掉 = 这个角色完全不读 AGENTS.md / CLAUDE.md）。

## 还原默认

面板右上角「还原默认」= 重新从 `$DSH_HOME/AGENTS.md` 复制一份覆盖这个角色的文件，
并清掉这一行被改过的键。

## 面板顺序

角色工作目录（只读）→ 身份与规则 → 能力行表（工具 / MCP / 插件 / 技能）。
要先填的在上，勾选类的在下。
