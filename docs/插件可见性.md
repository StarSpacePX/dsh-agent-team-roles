# 插件可见性

角色详情里的「插件」一块，按角色隐藏全局工具。

## 能关哪些

只列**根层（全局）注册**的工具：浏览器、MCP 连接器、宿主工具等。

预设在 agent 作用域里挂的工具（`pwsh` / `read` / `write` / `edit`、Agent Teams 的那几个团队工具）
不在这里——它们由上面「工具」那一组管。两条路的区别：

- 「工具」分组：关掉 = **不挂载**。
- 「插件」这一块：关掉 = **只隐藏可见性**，工具仍然存在。

## 怎么用

- 位置：**MCP → 插件 → 技能**。
- 每个工具一行开关；悬停显示工具名与描述。
- 标题行复选框 = 全开 / 全关，半选表示关了一部分。
- 同前缀且 ≥3 个的工具自动成组（浏览器类、MCP 类等），组头勾选框整组开关，默认收起。
- 输入过滤或勾上「只看被角色改过的行」时，分组自动摊开。
- 过滤框覆盖 MCP / 插件 / 技能三块；统计数字与列表同源，永远对得上。

## 生效

写入角色数据后后台重建；面板显示「已保存，重启 dsh 后生效」时，**重启 dsh 才生效**。

## 第一次打开要等

面板第一次读部署组合清单要 0.5~4 秒，冷启动更久，期间显示「正在读取角色…」。
启动 2 秒后会自动预热一次，之后打开基本即时。
