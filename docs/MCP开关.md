# MCP 开关

角色详情里的「MCP 开关」按**每个 MCP server 一行**列出，勾选即启用。

## 位置

搜索框正下方，与能力行分组同一层（不是缩进子层级）。
默认折叠，点标题左边的 `▸` 展开。

## 用

- **一个 server 一个勾选框**，这就是 MCP 这一维度的全部粒度，没有第二层总开关。
- 标题行复选框 = 全部 server 一起开 / 关，半选表示只开了一部分。
- 数据源是 MCP 连接器自己的存储（`~/.dsh/storages/mcp_connector.json`），插件**只读**。
  在连接器里增删 server，面板下次读取时就能看见。

## 关掉会发生什么

不是卸载 server（那会影响别的角色），而是给**这个角色**加一层隐藏：
把 `mcp__<server>__*` 从该 agent 能继承到的层里摘掉。这条隐藏层不提供任何工具。

关掉时按当时实际存在的工具现算，所以连接器后来增删、改名都不会残留。
