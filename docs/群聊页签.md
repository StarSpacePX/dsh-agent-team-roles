# 群聊页签

会话页签里多一个「群聊」页，只读，没有输入框。从会话页签栏点「群聊」进入。

页签从上到下四块：统计行、成员胶囊、角色依赖图、消息流。

## 统计行

| 项 | 含义 |
| --- | --- |
| `成员` | 这个会话里的团队成员数 |
| `消息` | 当前统计周期内的群聊条数 |
| `排队中` | 还没投递出去的消息数，为 0 时不显示 |
| `任务` | 任务板条数，没有任务时不显示 |
| `（历史未载完）` | 只读到会话日志的一段，更早的还在磁盘上 |

成员胶囊每个成员一个，写的是 `名字（Lead）· phase`，Lead 带括号标注。底色是成员自己的角色色。

历史未载完时，胶囊下方有「加载更早的消息」按钮，点一次往前翻 8 段，读取中显示「加载中…」。

## 角色依赖图

一行是对参与者之间的一次往返。

- 左边下拉：起点，选项是「第 N 次 @ · 时间」。
- 右边下拉：终点，首项是「最新（含 @ 之后的回复）」。
- 两个下拉中间是一个 `-`。
- 下一行「恢复默认（第一次 @ → 最新）」，一键把两端拨回。

每对参与者一行，Lead 恒在左侧。计数恒写成 `@n ⇄ @m` 两个方向都写，没有就是 0。

点一行展开时间线：时间、方向箭头、消息首行、`已送达` 或 `排队中`。

## 消息流

右上角两个按钮：`↑ 正序`、`↓ 倒序`，默认倒序（新的在上）。选择记在本机浏览器里，下次打开还是这个顺序。

每条消息显示：

1. 发送者 → 接收者，两个名字章。
2. 时间。
3. `已送达`（绿）或 `排队中`（红）。没投递出去就只有 `排队中`。
4. 正文，按 markdown 渲染。

每条消息整圈的边框是发送者颜色，平时四成淡，鼠标悬停变实色。

## 没内容时

| 情况 | 显示 |
| --- | --- |
| 窗口被截断 | 「这个窗口里没有群聊记录。」并可以点「往前翻日志找找（再翻 8 段）」 |
| 就是没有记录 | 「本会话还没有群聊记录。」并提示去 设置 → 插件 打开「智能体团队」 |
| 往前翻失败 | 「往前翻失败，请稍后再试。」 |

新打开页签、什么记录都还没看到时，插件自己先往前翻 8 段。每次打开页签会滚回顶部。

## 数据从哪来

两路合并，按消息 id 对齐：

- 当前会话的事件窗口：成员、任务、排队消息、已送达回执。任务被删除后不再显示，同一 id 只取最后一条。
- 宿主侧的整份会话日志投影，客户端每 4 秒拉一次，页面切到后台时暂停。

一条消息只要任一路看到「已送达」，就按已送达显示。

## 显示与隐藏

设置 → 插件 → 智能体团队 → 角色页，复选框「在会话页签里显示「群聊」」，默认开。

翻一下立刻挂上或摘掉，不用重启 dsh，也不用刷新页面。读不到状态时按「显示」处理。

这个开关的字段在宿主侧，所以升级插件后要先重启一次 dsh 才会出现；重启前复选框是灰的。
