# 说明书

面板上的说明文字（ⓘ 里的内容、按钮的悬浮提示）来自数据文件，不是写死在代码里。

## 改法

1. 角色页顶部点「**导出说明文件**」，得到一份列出所有键的 `notes.json`
   （放在角色数据目录，和 `roles.json` 同目录）。
2. 改里面的文案。
3. 点「刷新」，文案当场生效——每次读状态都重读这份文件。

## 规则

- 进文件的是**说明**。`共 12 行 · 显示 8 行`、`读预设清单失败：…`、
  `连接器里还没有任何 MCP 连接。` 这类是角色当前的状态，不能改。
- 缺键、空字符串、非字符串都回落到默认值，所以旧文件不会把新加的说明变空，
  插件新增键也不需要重新导出。
- 可用占位符：`{mode}` `{platform}` `{source}` `{parallel}` `{provider}` `{reason}` `{file}`，
  渲染时填。
- 一段说明可以由几个键拼成（如角色工作目录 = 主键 + 几个分句）。改分句只换那一句，
  改主键则整段用你写的那句。
- 文件是可选的：不导出就一直用内置默认值，插件不会自动往你目录里写文件。
- 文件写坏了（少个逗号之类）不会让面板变空：路径行下面会提示「不是合法 JSON」，文案按默认值渲染。
- 导出不会覆盖你已经改过的键：以「默认值 + 文件里已有的键」合并后写出。
