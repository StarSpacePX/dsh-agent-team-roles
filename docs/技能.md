# 技能

每个角色可以单独选用技能。

## 两种模式

| 模式 | 含义 |
| --- | --- |
| `inherit` | 默认，跟角色所用模式一致 |
| `pick` | 只挂勾中的技能 |

在列表里**勾一个技能就自动切到 `pick`**（勾选就是选用），不需要先开开关。

- 勾选名单两种模式都保留，来回切不丢。
- 每点一下立即保存，一个手势一个请求。

## 清单从哪来

宿主侧扫描这几个根，按优先级去重：

1. 项目 `.dsh/skills`
2. 项目 `.agents/skills`
3. `~/.dsh/skills`
4. `~/.agents/skills`

目录型技能要有 `SKILL.md`，单文件技能是 `.md` 本身；frontmatter 里没有 `name` 的条目不列出。
某个根不存在不算错。

## 行为

- **只接受这个部署真有的技能名**，不认识的名字直接报错「这个部署里没有技能：xxx」。
- 磁盘上被删掉的技能仍留在名单里，面板标「这个部署里已经没了，装回来才会挂载」，
  组合时不挂——不会因为少一个技能就让整个预设失败。
- 极简模式里没有技能相关行，勾技能会**成对补上**这两行。
- 部署级 provider 注册的技能对所有角色恒可见，这里只能同名遮蔽，不能删除。

## 生效

宿主侧改动**要重启 dsh**；面板刷新页面即可。
宿主侧还没重启时，面板显示「宿主侧还没重启」，不是坏掉了。
