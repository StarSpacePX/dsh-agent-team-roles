# 角色依赖图

群聊页签上方有一张依赖图：把消息按方向聚合成 `A → B` 箭头，每行右侧标这个方向的 **@ 次数**。
**点一下箭头就展开多行时间流**：每行一个时刻（精确到秒），带该条消息的正文摘要与送达状态。

## 读法

- **一对人一行**：两个方向都有就是 `A ⇄ B` 加两个计数；只有一个方向时显示 `A → B @n`，
  发起方在左。
- 展开后的时间流在双向行里用 `→` / `←` 标方向（相对左边那个人），单方向行不加。
- 三个人、四个方向就是两行。

## 收窄统计口径

两个下拉框分别选周期起点 @ 与终点 @（选项形如 `第 N 次 @ · HH:MM:SS`，只列 Lead 发出的 @）。
**默认是「第一次 @ → 最新」**，点「恢复默认」回到全量。
周期选定后，**消息流和依赖图一起收窄**。

## 前提

这个运行时默认是关的。没开「智能体团队」时，页签显示空态与开启方式
（设置 → 插件 →「智能体团队」，开启后重启 dsh）。
开着但没有团队事件的普通会话同样是空态。
