# 说明书

## 说明书是数据（`notes.json`）

面板上每一句**说明**（配置块标题旁边那个 ⓘ 里的文字、几个按钮的悬浮提示）都不是写死在代码里的，
而是一次查表：默认值在 `lib/notes.js` 的 `DEFAULT_NOTES`，覆盖来自 `<角色数据目录>/notes.json`
（和 `roles.json` 同目录）。改那句话不用改代码、不用重启：

1. 点「角色」页顶部的「**导出说明文件**」（`POST { "action": "export-notes" }`），得到一份列出**所有键**的 `notes.json`；
2. 改里面的文案；
3. 点「刷新」——宿主侧每次 `/state` 都重读这份文件，文案当场变。

- **不是每句话都能改**：进文件的是**说明**；`共 12 行 · 显示 8 行`、`读预设清单失败：…`、
  `连接器里还没有任何 MCP 连接。` 这类是**这个角色的事实**，留在客户端。
- **缺失的键回落到默认值**（空字符串、非字符串也一样）⇒ 老文件不会把新加的说明变空，
  插件以后新增键也不需要你重新生成文件；`/state.notes.custom` 会告诉你哪些键被文件改过。
- 文案里可以用 `{mode}` / `{platform}` / `{source}` / `{parallel}` / `{provider}` / `{reason}` / `{file}`
  这类占位，客户端渲染时填。
- **一段说明可以由几个键拼成**（「角色工作目录」那段 = `workdirIntro` + `workdirSource`/`workdirNoSource`
  + `workdirWithLoop`/`workdirWithoutLoop`；「模式」那段 = `modeIntro` + `modeKeepsOverrides` +
  `modeSnapshotMissing`/`modeMinimal`；「上下文继承主会话」= `contextOn`/`contextOff` + `contextProvider`
  + `contextOtherTool`、有行才显示）：改分句的键只换那一句，改这段的**主键**则整段就用你写的那句。
  分句的 key 必须用 `describe()` 取文本——`info()` 返回的是那个 ⓘ 元素本身，塞进 `note()` 会被
  静默丢掉、整段说明消失，所以 `npm test` 里有一条专门拦这个。
- 文件**是可选的**：不导出就一直用内置默认值（插件不会偷偷往你目录里放文件）。
- 文件坏了（比如手抖少个逗号）不会让面板变空：`/state.notes.error` 会说「不是合法 JSON」，
  界面上在路径行下面显示这行错误，文案仍然按默认值渲染。
- 导出**不会覆盖你已经改过的键**：它以「默认值 + 文件里已有的键（已有的优先）」合并后再写。
