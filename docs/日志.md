# 日志

插件不写自己的日志文件，走 dsh 的日志通道，logger 名固定为 **`agent-team-roles`**。
dsh 日志里带这个名字的行就是本插件输出的。

`DSH_HOME` 下没有本插件的日志目录，这是正常现象。

## 排查

1. 过滤 dsh 启动日志里的 `agent-team-roles` 行：安装、加载、配置归一化的结果都在这里。
2. 面板上的「已生效 / 已保存，重启 dsh 后生效」就是实际状态，不用靠日志猜。
3. 注册角色、绑定成员、写角色文件要重启 dsh 才生效；热加载只覆盖界面部分。
4. 数据直接看 `<DSH_HOME>/agent-team-roles/` 下的 `roles.json` 和每个角色的
   `role.json`、`AGENTS.md`。
